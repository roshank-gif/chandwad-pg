CHANDWAD PG - PG finder website for Chandwad city

LOCAL TEST (JDK 17+): java Main.java  -> http://localhost:8080
ONLINE: push this folder to GitHub and deploy as a Docker web service
        (Dockerfile included). Set DATA_DIR=/data and attach a persistent disk at /data.
Env vars: PORT (default 8080), DATA_DIR (default ./data)
